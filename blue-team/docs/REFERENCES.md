# Primary References

- NIST Cybersecurity Framework 2.0 — governance and the concurrent Govern,
  Identify, Protect, Detect, Respond, and Recover outcomes:
  https://doi.org/10.6028/NIST.CSWP.29
- MITRE ATT&CK Enterprise tactics and detection strategies:
  https://attack.mitre.org/tactics/ and https://attack.mitre.org/detectionstrategies/
- CISA Federal Government Cybersecurity Incident and Vulnerability Response
  Playbooks — standardized identification, coordination, remediation, recovery,
  and mitigation tracking:
  https://www.cisa.gov/topics/cybersecurity-best-practices/executive-order-improving-nations-cybersecurity
- Sigma specification — portable rule and correlation concepts:
  https://sigmahq.io/sigma-specification/

These references guide the operating model. Sentinel Blue's JSON rule format is
intentionally smaller than Sigma and does not claim Sigma compatibility.
